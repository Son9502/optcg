OPTCG Match Sim

A rules engine for the One Piece Card Game that reads printed card text and turns it into game logic the engine can run. It runs in the terminal today; the next milestone is a complete game against an AI opponent, as a practice tool for learning the game correctly.

From card text to game logic

Effects aren't hand-coded card by card. An offline pipeline reads each card's printed ability text and compiles it into structured data the engine executes.

1

CardScraper

Pulls raw card JSON from the community optcgapi.com API.

2

Parser

Splits text into abilities: trigger, condition, cost, effect.

3

EffectLexer

Longest-phrase-first scanner that emits 13 token types.

4

EffectParser

Turns tokens into typed effects with targets, filters and durations.

5

CardDatabase

Loads compiled JSON; the engine hydrates runtime abilities from it.

Ability text in

[When Attacking] +2000 power this turn.

Structured ability out (simplified)

trigger:  WHEN_ATTACKING
effect:   POWER_BOOST +2000
target:   this card
duration: THIS_TURN

The output is simplified for readability; the real compiled JSON carries more fields. CardCompatibilityReport then checks every card against the engine and lists anything not yet supported.

What the engine enforces

Rules follow Bandai's Comprehensive Rules, with § citations throughout the code docs.

Turn & battle

  • Refresh → Draw → DON → Main → End
  • Mulligan
  • DON!! cost payment
  • Summoning sickness
  • Blocker → counter → resolve
  • Life & Triggers
  • 5-character / 1-stage limits

Keywords & effects

  • Rush
  • Rush: Character
  • Blocker
  • Double Attack
  • Banish
  • Unblockable
  • Counter
  • Search deck
  • Modal choices
  • Negate
  • 4 effect durations
  • 9 activation cost types

Test coverage

370 tests across 16 classes. Effect resolution carries the most weight, because that's where card text meets the rules.

10 CardDatabaseTest cases need locally scraped card data and skip cleanly without it.

Roadmap

The goal is a learn-and-practice tool: play correctly, understand why a move is good, find decks that fit how you play, and learn the leaders.

  • Done
    Phases 0–2: rules engine and card pipelineFull rules engine, card pipeline, ability system and keywords; 29 of 29 Phase 2 items complete.
  • Next
    v1: learn and practice in the terminalReal starter decks, an AI opponent with difficulty levels, a "what's the best move and why?" advisor, and a short walkthrough.
  • Planned
    v1.5: find your playstyleA short beginner quiz and a few teaching decks, then recommendations for colors, decks and matchups based on how you actually play, with the reasons explained.
  • Planned
    Leader guidesHow to play each leader: win plan, key cards and practice games with the advisor. Added leader by leader as engine coverage grows.
  • Planned
    v2: play in the browserThe same game against the AI, right on this site, driven by JSON game-state snapshots over WebSocket.
  • Planned
    v2.1: game recordingEvery game saved as a replayable action log, building the dataset the v4 AI learns from.
  • Planned
    v3: deck builder and online playBuild and rate decks, play friends online, run tournaments.
  • Planned
    v4: stronger AISearch-based play (ISMCTS) and OpenSpiel-trained opponents, including "play like this deck" simulation.
  • Planned
    ML trackFirst, a model that reads printed card text into the engine's effect format, tested on sets it has never seen. Then models trained on AI-vs-AI games (deck strength, win probability, self-play RL), each ranked on a public, reproducible bot ladder.

Run it locally

Requires Java 21 and Maven 3.8+.

git clone https://github.com/Son9502/optcg.git
cd optcg
mvn compile
mvn exec:java -Dexec.mainClass="engine.Main"   # play
mvn test                                       # 370 tests
